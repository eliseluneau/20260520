Overview

What is Claude Code?

An AI assistant that works directly with your files — from your terminal, inside your actual project folder.

01
Terminal-based
Runs in your command line. No browser tab — Claude lives where you actually work.
02
File-aware
Reads and writes files on your computer. Scans your entire folder to understand the full context.
03
Subscription-based
No freemium restrictions — requires a Claude plan, but unlocks full capabilities across your workspace.
💡 Not a terminal person? The Claude Code app gives you the same power in a friendlier interface — no command line required.

Claude Skills

Package expertise as /your-command — reusable, shareable, instantly powerful.

What is a skill?
A prompt-engineered context space that gives Claude deep, reusable expertise for a specific task. Think of it as a "second brain" — someone has already found the optimal way to prompt your workflow so you don't have to start from scratch.
How to use it
Open Claude → type /morning (or any skill). Claude reads all files in your workspace and delivers exactly what the skill is designed for: insights, priorities, to-dos — knowing the full context.
Download pre-built skills Build your own Connect to Linear, Slack, GitHub…
💡 Skills are essentially expertise packaged as a prompt — once built, anyone on your team can invoke them with a single slash command.

Advanced

MCP Servers

Model Context Protocol — the bridge that lets Claude talk to external APIs efficiently and securely.

🔌
What is MCP?
A standard protocol that connects Claude to third-party services — like a universal adapter between AI and any API.
⚡
What it enables
Connect to Linear for tasks, Slack for messages, GitHub for code, Gmail, calendar — anything with an API.
🚀
Why it matters
No copy-pasting between tools. Claude fetches, updates, and acts on real data in your actual systems — live.
Example: /morning skill + Linear MCP → Claude reads all your open tickets, prioritises your day, and can create or update tasks — all from a single command.
