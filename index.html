Overview

What is Claude Code?

Like claude.ai in your browser — but it works on your actual files, reads and writes them, and can use tools beyond just replying to messages.

01
Works on your files
Reads and writes files directly on your computer. Operates inside one folder — it will not crawl your entire system.
02
More than a chatbot
Can use tools, run web searches to benchmark data, connect to external services via MCP servers — all without leaving your workflow.
03
€20/month, no freemium
One Claude subscription covers all interfaces: browser, terminal, Excel plugin, desktop app. No free tier — but one plan unlocks everything.
💡 Not a terminal person? The Claude desktop app gives you the same power in a friendlier interface — and that's what we'll use for Demo 2.
Setup

Getting Started

Install once, then navigate to any folder and type claude. It figures out the rest.

1
Install Claude CodeCopy the one-line command from claude.ai/code, paste it in your terminal. Type claude login the first time to authenticate.
2
Choose your folder & initialiseNavigate to the folder you want Claude to work in. Run /init — Claude generates a claude.md file at the root to anchor every future conversation to that workspace.
3
Start workingType claude to launch. All commands start with / — that's why you hear "slash commands." Claude stays inside your folder and won't touch the rest of your computer.

Demo 2 The Second Brain

Claude Skills

Clara is a UX designer. Her workspace holds her journal, call transcripts, and an idea maturation funnel. One slash command gives her a morning brief.

What a skill is
A plain text file (skill.md) that encodes a repeatable task as precisely as possible. Stored in .claude/skills/morning/, invoked as /x·morning — the x prefix distinguishes your skills from downloaded ones.

You can ask Claude to write the skill for you: describe your workflow once and it does the engineering.
What the morning brief surfaced
After reading all of Clara's files, Claude flagged three things unprompted:

🔴 Mark — pattern of unpaid hours + red flags in journal. Verdict: stop negotiating with yourself.
💰 Rate hesitation — recurring across multiple notes. Verdict: raise your prices.
✂️ Side project — quietly omitted. Claude judged it a distraction and didn't clutter the brief.
💡 "A skill is any piece of work you want done in a certain way. Once you've done it once — crystallise it." — Hadrien
Demo 2 Under the hood

How Skills Work

Workspace file structure

📄
claude.md (root) — auto-generated on /init. Read at the start of every conversation to keep Claude focused on this workspace.
📁
.claude/config/ — hidden folder. Claude loads MCP connections and tools from here automatically on startup.
📁
.claude/skills/morning/skill.md — one file per skill. The folder name becomes the slash command: /x·morning.
🧠
Context builds over time — add more relevant files to the workspace and Claude's answers gradually get sharper.

Clara's idea maturation funnel

💡 Raw ideas/
Dump ideas here to clear headspace. No pressure to act — just offload them so they don't occupy working memory.
🧪 Experiments/
Ideas worth testing. E.g. "Should I productise UX audits?" — moved here when she decides to try it.
✅ Outcomes/
Concluded experiments with a clear verdict. Claude reads the full arc and advises accordingly — without being told the history every time.
Demo 3 Product brief → Linear tickets via MCP

Claude + Linear

A SaaS product brief lives in the workspace. One prompt turns it into user stories — then pushes them live into Linear, spread across 5 weeks.

The workflow

1
Brief → user stories — Claude reads the product brief and breaks it into actionable development stories. No PM experience needed.
2
Stories → Linear — "Take all user stories and put them in Linear, spanning the next 5 weeks." Claude calls the Linear API via MCP and creates issues live.
3
Visible in real time — issues appear in the Linear board as Claude works. No copy-paste, no manual ticket creation.

What is MCP exactly?

🔌 A wrapper around an API
Linear already has an API. The MCP server is how an LLM like Claude can call that API efficiently and in a predictable way.
⚡ No MCP? Claude improvises
If no MCP exists, Claude tries the CLI, or writes a plain Python / Ruby script to reach the same outcome.
🎯 The right mindset
"Try ambitious. Only fine-tune if you get stuck." Claude is creative enough to find a path even without perfect tooling.
Demo 3 Advanced

MCP Servers

Model Context Protocol — the standard that lets Claude act inside your real tools, not just talk about them.

🔌
What is MCP?
A protocol that wraps any existing API so an LLM can call it reliably. If a tool has an API (Linear, Slack, GitHub, Gmail…), it can have an MCP server.
⚡
What it enables
Claude moves from reading and writing local files to acting in external systems — creating tickets, sending messages, querying live data — all from one prompt.
🚀
How to set it up
Add the MCP server config to your .claude/config/ folder. Claude detects it at startup and gains access to that tool automatically.
Performance note: Running 5–6 Claude projects in parallel causes no noticeable slowdown — tested on a 2021 MacBook Pro.
